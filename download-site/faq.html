Orbit FAQ

Direct answers before you operate or install.

These answers describe behavior established in the current Orbit repository. They do not add pricing, customer claims, or unreleased functionality.

Contact support
ScopeWhat does Orbit connect?

Orbit connects live poker room demand, waitlists, check-in, seating, table state, memberships, tournaments, and closeout reporting. Orbit Core is the management desktop application; Orbit Player is the player-facing application for participating rooms.

WorkflowHow do player requests reach staff?

Authenticated players can send membership and waitlist requests through Orbit Player. The backend validates identity and tenant scope before the request becomes available to the participating room's staff workflow.

ConnectivityDoes Orbit Core work without a connection?

Orbit Core keeps local persistence as an offline cache. Durable shared state remains server-owned, and realtime publication or reconciliation requires a connection. Revision and conflict semantics prevent a local cache from silently becoming the shared authority.

IdentityHow are player and staff privileges separated?

Orbit Player uses Firebase Authentication for player identity. Tenant and staff role privileges are verified by trusted server or desktop main-process boundaries rather than accepted from browser-selected state.

ReleaseCan I download Orbit Core now?

Yes. The public page links to the approved, verified Windows x64 installer as an immutable GitHub release asset. The release manifest and visible download action identify the same versioned file.

PlatformWhich desktop platform is listed?

The current public release manifest identifies Orbit Core for Windows x64. A release is not treated as production merely because code reaches the main branch.

Account helpHow can a Player account be deleted?

Use the account deletion action in Orbit Player's Profile and Settings area. If you cannot access the app, call Orbit support for help with the request.

Need help with a specific account or installation?

Do not include passwords, pilot keys, or other credentials when requesting support.
