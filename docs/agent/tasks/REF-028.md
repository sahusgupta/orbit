# REF-028: Execute measurement-driven performance improvements

Status: `in_progress`

Date: 2026-08-10

## Objective

Re-measure the modularized renderer and Player subscription boundaries, then accept only changes with a reproducible material improvement while preserving route output, data freshness, subscription cleanup, error/fallback semantics, and existing on-demand imports.

## Measurement method

`npm run measure:renderer-bundle` performs a production-config Vite/Rollup build entirely in memory (`write: false`) and reports exact emitted and gzip bytes, static/dynamic chunk edges, and the largest rendered module contributors. It does not start the renderer, Electron, the API, Firebase, or any hosted service.

The ordinary release configuration is intentional for bundle fidelity: setting `VITE_ENABLE_FIREBASE_SYNC=false` at compile time changes tree shaking and does not represent the shipped default. Runtime checks, if any become necessary, must instead use disabled Firebase sync and an unreachable loopback API.

## Characterization gate

Before changing production imports, the established REF-006 route contract suites passed 10 files / 36 tests. They cover Outreach, Tonight/builder, Profiles, Tournaments, Reports/KPIs, Settings, Table, Floor, tournament lifecycle, and night-close lifecycle DOM/callback behavior.

The Player subscription candidate was inspected but not selected: it already rejects overlapping refreshes, pauses the polling timer outside the active app state, refreshes on foreground return, and tears down parent/child listeners and timers. Its existing lifecycle tests cover those policies. No measured redundant workload supports changing freshness or polling behavior.

## Acceptance threshold

The route-loading change will be retained only if the production-config measurement materially reduces startup JavaScript bytes and all characterized routes settle to their unchanged output. ExcelJS and ZXing must remain on-demand. Any candidate without a material measured gain will be reverted rather than committed.
