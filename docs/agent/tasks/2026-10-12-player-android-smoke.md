# Isolated native Android smoke

This continuation adds a repeatable engineering test for the standalone QA snapshot, using only package `com.orbit.player.qa`, serial `emulator-5580` and dedicated ADB port `5039`. [The runner](../../../tests/e2e/player-android-qa/smoke.mjs) and [commands and boundaries](../../../tests/e2e/player-android-qa/README.md#native-ui-smoke) are task-local. It does not change player production source, auth/data contracts, dependencies, native build configuration or host device/network settings.

The actual native entrypoint is `player-app/App.tsx` → `src/PlayerApp.tsx`. Demo uses real `useDemoPlayerSession`, `createDemoPlayerData` and an in-memory Match controller; it must reset after cold launch. A completed guest profile uses actual local account storage and the device Match journal. The offline guest path in `usePlayerIdentity.finishAccount` writes local state without calling authenticated profile resolution. The runner supplies only synthetic `Android QA Fixture` / `android.qa@example.invalid`; no connected account, contact delivery, ID or payment action is requested. The separately approved permission case requests and denies only location permission, retaining manual fallback without reading coordinates.

Preflight is fail-closed before any app install/start: the target is a booted emulator; airplane mode is on; Wi-Fi/mobile are off; IPv4 routes are empty; IPv6 has no default; guest Ethernet/Wi-Fi are DOWN; connectivity has no active default network. The parent owns emulator preparation and explicitly confirmed these guest conditions. A build remains necessary before native execution. Every ADB call pins serial/port and carries an isolated Android home and ADB key **path only**. Key material is never read or logged. Optional install verifies a parent-approved APK SHA-256 and exact package/launcher through public SDK tooling. Optional fresh-state clearing addresses only the QA package.

Prepared UI cases cover light/dark actual native onboarding/demo/Home/Match, short gesture rejection, pass and Undo, save and Saved/details/back-mode, operational demo notices, manual coordinate validation, hidden demo GPS action, 44 dp Save target, 150% native font scale, animation/reduced-motion settings, live OS scheme switch, the two club memberships and four published Map venue-list records, QR suppression, reset/exit, demo cold-launch reset and local guest profile/preferences/manual-origin restoration. OS settings restore in `finally`. Screenshots and UI evidence are ignored artifacts; visual/native accessibility acceptance cannot be inferred from source assertions alone. Package-scoped `am start -W` and `gfxinfo` are emulator observations only.
