# REF-012: Extract management profile-import parsing and normalization

Status: `complete`

Date: 2026-08-08

## Objective

Move CSV/XLSX/pasted-JSON record interpretation, canonical profile construction, duplicate-name filtering, and companion-link enrichment out of `src/main.tsx` into a pure module without changing supported inputs, defaults, identity, ordering, notices, or persisted profile shapes.

## Characterization

The existing five-case pasted-profile suite passed before production edits. Characterization commit `f42e297` added two cases against the unchanged `App`:

- quoted CSV aliases, escaped quotes, duplicate-name skipping, and companion name-to-profile-ID enrichment;
- XLSX header projection, `Date` cells, Excel serial dates, numeric values, game aliases, and movement flags.

The XLSX case uses a deterministic worksheet fake. It verifies Orbit's ExcelJS-facing header/row contract without using real timers or retesting ExcelJS internals. The unchanged implementation passed all seven renderer cases, followed by `npm run verify` at 55 files / 308 tests.

## Implementation

- Added `src/domain/profileImport.ts` as the platform-independent owner of CSV parsing, spreadsheet alias/date/number interpretation, pasted JSON/text validation, canonical `PlayerProfile` construction, canonical table-tag filtering, existing-name filtering, input-preserving companion enrichment, and explicit import results.
- Added `src/domain/profileImport.test.ts` with four direct cases for CSV quoting, spreadsheet normalization, malformed JSON/text fallback, deduplication, companion linking, and input immutability.
- `src/main.tsx` now supplies explicit games, ID, date, game-resolution, and valid-tag dependencies. It retains file selection, the lazy ExcelJS workbook load, user feedback, usage reporting, and persistence.
- The supported file/pasted formats, eager spreadsheet defaults, Excel serial-date epoch, JSON malformed-member skipping, invalid-number fallback, game resolution, input ordering, duplicate policy, and persisted profile shape remain unchanged.

`src/main.tsx` decreased from 5,685 to 5,464 lines. Its `App` function decreased from 5,086 to 4,858 lines. The new focused production module is 287 lines and contains no explicit `any`.
