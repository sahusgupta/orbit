# Orbit Match isolated browser runtime QA

The engineering entrypoint is [the QA runner](../../../tests/e2e/player-match-smoke.mjs), documented in [its README](../../../tests/e2e/player-match-qa/README.md). It imports actual native presentation/domain/controller modules through React Native Web, and uses only a synthetic actor and localhost HTTP adapters. The backend Match service runs against an injected transaction store; no real Firebase/auth/service target is initialized. Production client ports are rejected from the bundle, non-loopback browser requests are blocked and generated artifacts remain ignored under `out/player-match-qa/`.
