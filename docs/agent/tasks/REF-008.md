# REF-008 - Extract Electron process modules

Status: active

## Objective

Make `electron/main.cjs` primarily wire reviewed Electron/Node modules while preserving the preload bridge, IPC contract, SQLite shapes, API/Firebase fallback order, sync protocol behavior, update flow, security settings, and failure semantics.

## Preconditions and safety

- TYPE-016 is complete; `electron/main.cjs`, `electron/preload.cjs`, and `electron/firebaseSync.cjs` pass dedicated non-DOM check-JS.
- Every production move from `electron/main.cjs` requires focused characterization committed against the unchanged owner first.
- This task must not launch Electron, read a pilot private key, run `npm run stress:e2e`, contact hosted APIs/Firebase, send messages/email, publish an update, or change a database/schema.
- Module APIs remain process-local CommonJS. Renderer/preload exposure does not expand.
- Firebase/player request transformation remains in `main.cjs` until REF-009 decides and characterizes shared sync ownership.

## Sequence

| Subtask | Scope | Required characterization |
| --- | --- | --- |
| REF-008A | Pure error, validation, outreach-message, and account-key utilities | exact errors, field preservation, filtering/cap/order, precedence/fallback, immutability |
| REF-008B | API client and client telemetry | URL/auth headers, timeout/error projection, API-first/fallback results, telemetry payload/event routing |
| REF-008C | Local SQLite state and analytical reports | paths, legacy/account reads, writes, report validation/storage/email fallback, row/result shapes |
| REF-008D | Embedded localhost HTTP backend | localhost binding, routes/statuses, request limits, auth/account isolation, delegated mutations |
| REF-008E | Auto-update orchestration | status/event sequence, state-preservation handshake, idempotent install, timer/listener ownership |
| REF-008F | Final window/IPC composition audit | exact IPC channels, navigation allowlist, sandbox/context isolation/node-integration invariants |

## Progress

### REF-008A - Runtime utilities

- Characterization commit: `ae7882b` (`test: characterize Electron runtime utilities`).
- Implementation: moved pure record/error helpers, state validation, outreach-batch normalization, and account-key derivation into `electron/runtimeUtils.cjs`; `electron/main.cjs` imports the same process-local CommonJS API.
- The focused tests load the extracted module directly while retaining the existing source-isolation harness for runtime owners not yet moved.
- Verification after implementation: `npm run typecheck:electron`, the focused six-test file, `npm run typecheck`, `npm run build`, and `npm run verify` all passed. The full gate covered 41 files / 214 tests and 1,930 renderer modules.
- No Electron process, hosted endpoint, Firebase path, messaging provider, updater, or database was invoked.

### REF-008B - API client and client telemetry

- Characterization commits: `0735d60` (`test: characterize Electron API client boundary`) and `5478ec4` (`test: characterize Electron telemetry identity`).
- Implementation: moved authenticated API transport, pilot/state/report projections, device identity, client telemetry state/routing/timer ownership, and API-first fallback orchestration into `electron/orbitApiClient.cjs`.
- The process-local factory receives local-state, Firebase, reporting, clock, timer, device-path, identity, logging, and transport dependencies explicitly. `electron/main.cjs` retains IPC, local SQLite/report owners, player-sync transformations, and lifecycle composition.
- The characterization suite now loads the extracted module directly and covers 14 API/fallback/telemetry cases; the companion Electron findings suite contributes another six focused cases.
- Verification after implementation: both focused files (20 tests), `npm run typecheck`, and `npm run verify` passed. The full gate covered 42 files / 228 tests and 1,930 renderer modules.
- No Electron process, hosted endpoint, Firebase path, messaging provider, updater, or database was invoked; all transport, persistence, timer, and fallback collaborators were isolated fakes.

## Acceptance

- Characterization and implementation remain separate commits for each risky boundary.
- `electron/main.cjs` primarily composes imports, Firebase-request synchronization, IPC handlers, windows, and application lifecycle.
- Extracted modules have explicit dependency injection where it prevents hidden process/global coupling and can be tested without Electron or external services.
- Electron check-JS, focused tests, both root compiler projects, Player TypeScript, all unit tests, renderer build, and `npm run verify` pass after every implementation subtask.
- Documentation records any cohesive responsibility deliberately left in `main.cjs`; no production-connected harness or deployment is run.
