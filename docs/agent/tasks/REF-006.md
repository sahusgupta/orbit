# REF-006: Split renderer route sections into typed feature components

Status: `active`

Date: 2026-08-07

## Objective

Move each large route-owned JSX branch from `src/main.tsx` into a typed feature component while retaining top-level state, effects, commands, route selection, shell composition, and mutation orchestration until separately characterized.

## Execution constraints

- Extract one route and one committed characterization boundary per subtask.
- Preserve DOM structure, classes, labels, control order, event timing, and callback semantics.
- Pass typed values and callbacks; feature components must not gain persistence, Firebase, Electron bridge, or global-state ownership.
- Keep `AppShell` composition in `main.tsx` during the first route moves so navigation and notification behavior remain centralized.
- Do not combine route extraction with styling, data redesign, callback rewrites, or opportunistic cleanup.
