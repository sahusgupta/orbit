# REF-007 - Split the ordered global stylesheet by feature

Status: complete

## Objective

Move the 8,840-line management renderer cascade out of one global file into explicit local owners without changing selector order, specificity, declarations, responsive behavior, theme behavior, or rendered pixels.

## Boundary and safety

- Scope is `src/styles.css`, new files under `src/styles/`, focused stylesheet characterization, and the architecture/task records that describe this move.
- This is relocation, not a visual redesign or CSS cleanup. Duplicate and historical override rules remain until a separately characterized task authorizes semantic consolidation.
- `src/styles.css` remains the renderer entrypoint and may contain only ordered local imports after extraction.
- The original flattened cascade is characterized by SHA-256 `eff755a4abfb757027fe042514ed995aa9968e89bdbfb45e17414453fd895ad2` over 234,316 UTF-8 bytes. Imported slices must flatten to those exact bytes.
- Runtime comparison uses only a local Vite server with `VITE_ENABLE_FIREBASE_SYNC=false`, `VITE_ORBIT_LOCAL_API_URL=http://127.0.0.1:9`, `ORBIT_ENABLE_FIREBASE_SYNC=false`, and `ORBIT_API_URL=http://127.0.0.1:9`. It must not contact Firebase, the hosted API, Electron, or production data.

## Characterization

- `src/styles.order.test.ts` recursively expands local CSS imports and pins the original ordered cascade byte-for-byte.
- `tests/e2e/ref007-styles-rendered.mjs` seeds a deterministic local account and captures eight representative route/theme/viewport combinations: Floor in wide light and compact dark modes, Table, Players, Games, Tournaments, Reports, and Settings.
- Baseline and comparison images are generated under ignored `.orbit/` paths and are not committed.
- The browser comparison must be shown deterministic by comparing two captures before production CSS moves, then pass again after extraction. It permits only headless Chromium raster noise of at most 100 pixels with a maximum three-level channel delta per image; dimensions and all larger differences fail.

## Acceptance

- Every original CSS byte appears once and in the same flattened order.
- Feature, shell, responsive, theme, accessibility, and compatibility slices have explicit ordered owners under `src/styles/`.
- The focused cascade test passes before and after extraction.
- All eight rendered comparisons are identical before and after extraction at their characterized widths/themes within the explicitly bounded Chromium raster tolerance above.
- Root renderer/test TypeScript, Player TypeScript, the full unit suite, renderer build, and `npm run verify` pass.
- `docs/architecture/CURRENT_STATE.md` and `docs/refactor/TASKS.yaml` describe the resulting ownership and accurate current line counts/status.
- No API/data contract, renderer state, synchronization, external service, dependency, deployment, or generated artifact is changed or committed.

## Implementation and verification

- Replaced the monolithic `src/styles.css` body with 35 ordered local imports and moved the unchanged 8,840-line cascade into explicit owners under `src/styles/`; `src/styles/README.md` documents ownership and the ordering contract.
- The recursively flattened source remains exactly 234,316 UTF-8 bytes with SHA-256 `eff755a4abfb757027fe042514ed995aa9968e89bdbfb45e17414453fd895ad2`.
- A build-time parse failure exposed one comma-separated selector boundary during implementation; the selector was kept intact in `30-table-surface.css` before verification. No CSS declaration or selector changed.
- The eight-case rendered comparison passed after a clean isolated-server restart. Floor light/dark, Table, Players, Games, Tournaments, Reports, and Settings remained within the characterized Chromium raster tolerance.
- Both root compiler projects and Player TypeScript passed; all 40 test files/208 tests passed; the 1,930-module renderer build passed; and `npm run verify` passed.
- The generated CSS asset remained `index-DGbFTm5X.css` at 188.71 kB (34.03 kB gzip), corroborating the source-cascade and rendered equivalence checks.
- Only the existing SQLite experimental, ExcelJS `eval`, and large-chunk warnings were emitted. No production service, Electron runtime, deployment, or generated screenshot was used as a repository artifact.
