## Change and preserved behavior

The production patch adds three URL query lines. Every reconciliation page requests `syncSource`; player pages also request `sourceProfileId`. Every fresh legacy-player page requests only `sourceProfileId`. These are all fields the respective cleanup consumers read. Document names, response envelopes and opaque tokens remain available. No generic partial-response `fields`, update mask, filter, ordering, index or authorization change is introduced.

Page size remains 500. Each page reconstructs the same mask before encoding its opaque continuation token. Existing cycle detection, missing/malformed-field handling, response/body deadlines, redacted failures, bounded delete batches and acknowledgement handling are unchanged. Upserts still precede stale cleanup; observed legacy candidates are freshly rechecked afterward; the parent remains the last acknowledged commit marker. Existing legacy cleanup can remove a noncanonical known-profile row regardless of its syncSource. Unlinked foreign records remain protected by the existing rules; no broader foreign-record protection is claimed.

Orbit API response contracts, persisted document shapes, player payloads, sync-v2 revisions, public exports, optimistic UI behavior and all writes are unchanged. The baseline's synthetic provider now honors the same supported top-level masks instead of returning whole records regardless of the URL, and exposes `listResponseBodyBytes`. Its full backing store remains independent of projected responses. Unsupported synthetic mask paths fail explicitly.
