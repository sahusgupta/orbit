# Map handoff to the selected venue's games

The Map's **View games at a venue** action updated only the card-house filter. The existing discovery helpers filter casinos separately, so choosing a house also admitted casinos, and choosing a casino could retain a different casino filter. An unrelated game search, Favorites/type filter or stakes text could also hide the selected venue. This affected cash and scheduled Match candidates through the actual [PlayerApp callback](../../../player-app/src/PlayerApp.tsx), rather than the Map's visual presentation.

The narrow correction changes only that `onShowGames` callback. It clears transient game query/type/stakes/fit filters, selects the clicked venue in its correct family and sets the opposite venue family to `none`, then uses the existing Discover mode and route. Persisted Match preferences, strict limits, radius, exclusions, saves and passes are unchanged. The Map action does not save a game, send a seat request or express tournament interest. Explicit Match exclusions and strict preferences still apply, so an excluded venue may correctly have no recommendations.
