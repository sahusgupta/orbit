# REF-020: Consolidate the management composition root

Status: `complete`

Date: 2026-08-08

## Objective

Reduce the management `App` to cross-feature state/effects, application-command invocation, persistence calls, dialogs, and route composition by moving cohesive UI drafts, derived route view models, typed presentation contracts, and residual presentation into feature owners. Preserve DOM structure, route hashes, callback timing, state ownership, focus/dialog behavior, styles, persisted shapes, and domain failure semantics.

## Characterization gates

Each feature move used its existing renderer and command boundary immediately before and after production relocation:

- Tournament: 3 files / 7 tests (`tournamentView`, `tournamentLifecycle`, and tournament commands).
- Profiles/membership: 7 files / 41 tests covering relationships, import, grouping, quick add, QR validation, profile commands, and membership commands.
- Settings/account: 6 files / 24 tests covering settings rendering, restore, pilot signature, recovery, and browser/desktop persistence behavior.
- Reporting/closeout: 4 files / 12 tests covering the night-close lifecycle, table-event reporting, report projections, and closeout commands.
- Floor/table: 11 files / 68 tests covering quick add, table planning/lifecycle, player transitions, seat normalization, floor callbacks, poker-table rendering, and table/player/seating commands.
- Games builder/outreach: 4 files / 21 tests covering candidate parsing/rendering, result builders, participant planning, and table planning.
- Table-ledger presentation: 3 files / 22 tests covering player transitions, floor collection callbacks, and quick add.

No new behavioral test seam was required: the moves were relocation and typed state composition behind already-green route matrices. No production service, remote endpoint, credential, database, Electron process, or deployment command was used.

## Implemented ownership

- `src/features/tournaments/tournamentWorkspace.ts` owns tournament selection, form/player/payout drafts, section/view state, timer projections, and typed action assembly.
- `src/features/profiles/profileWorkspace.ts` owns profile/import/check-in drafts, membership/QR dialog state and scanner lifecycle, profile view-model selectors, and typed edit contracts.
- `src/features/settings/settingsWorkspace.ts` owns access/login/setup/club/staff/settings UI state, backup/report feedback, and the two characterized license/account synchronization effects.
- `src/features/reporting/reportingWorkspace.ts` owns report/closeout UI state, memoized report projections, the local-date contract, and the pure night-close presentation model.
- `src/features/floor/floorWorkspace.ts` owns quick-add, table-dialog, ledger/event selector, collection-entry, panel/collapse, waitlist, and seat-picker state plus Escape-to-close behavior.
- `src/features/games/gamesWorkspace.ts` owns builder filters/coordination and outreach candidate/text state. Its candidate contract aliases the canonical parser result rather than duplicating a component-local shape.
- `src/features/floor/TableBuyInLedger.tsx` owns the relocated ledger markup and reconciliation presentation. The raw-entry ordering, totals, labels, and symbols are unchanged.
- `SummaryView`, `SettingsView`, `FloorView`, `TableView`, `BuilderView`, `SignalsView`, `ProfilesView`, and `TournamentsView` consume feature-owned types instead of redefining their draft contracts.

`src/main.tsx` retains the five application-wide state declarations: canonical management state, route, shell notification visibility, undo history, and the shared clock. It continues to compose synchronization/persistence hooks, invoke pure application commands, attach usage/persistence effects, construct dialogs, and select typed route components. No persistence or domain algorithm moved into presentation.

Two unused feedback state slots and their unreachable local handler were removed after repository-wide call-site searches found no reads or invocations. Two other unreachable local components were removed; the one live residual component, the table ledger, moved to its feature owner.
