# REF-001: Extract canonical management domain types

Status: `complete`

Date: 2026-08-07

## Objective

Give the management renderer's persisted state and entity contracts a focused owner without changing runtime behavior, persisted shapes, or public synchronization contracts.

## Characterization basis

This is a type-only relocation. The recently committed stabilization suites already characterize the affected renderer mount, persisted-state, licensing, identity, waitlist, seating, table, tournament, reporting, and synchronization boundaries. No additional runtime test was added because the production JavaScript is expected to be byte-for-byte equivalent.

Before the move, all 15 renderer-mount suites passed (76 tests) as part of the green stabilization baseline. After the move, the same 15 suites passed 76 tests and the complete suite passed 35 files/188 tests.

## Implementation

- Added `src/domain/types.ts` as the owner of 45 management domain, persisted-state, identity, tournament, revenue, and route contracts.
- Replaced local declarations in `src/main.tsx` with type-only imports.
- Kept UI-only drafts/results and all runtime constants/functions in `src/main.tsx`.
- Represented the existing `6 | 8 | 10` table-cap contract explicitly and retained the identical runtime array with a compile-time `satisfies` check.
- Did not change helper contracts, state normalization, persistence, preload IPC, Firebase, API, or Player code.
